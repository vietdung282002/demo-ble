BLE proximity login

Scan the QR code with the demo app, then connect over Bluetooth. Only a phone within radio range can finish the handshake.

Web Bluetooth is not available in this browser. Use Chrome or Edge on desktop, served from http://localhost.

  5. Phone approved the challenge
